### DESIGN 

#### BRANDING

- Font:
Google Fonts: Caveat Brush, Static (web):
[https://fonts.google.com/specimen/Caveat+Brush?preview.script=Latn]
    
Code to insert in <head> section (HTML [index.html]):
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Caveat+Brush&display=swap" rel="stylesheet">

Code to insert in stylesheet (CSS [style.css]):
.caveat-brush-regular {
    font-family: "Caveat Brush", cursive;
    font-weight: 400;
    font-style: normal;
}

- Background:
Background-image sourced from [freepik.com].

- Colour palette:
    - Coral tones used, to create warmth and a cosy atmosphere, while still remaining fairly gender-neutral. 


#### STYLING 

- Borders:
Some divs/buttons have dashed borders to emulate a stitch pattern, keeping in theme with the crochet/textile genre of the business.

- Colours:
The colours used all tie together with variety in shades and tones of the same base colours selected for the palette.

- Transparency/Opacity:
The background remains a solid level while the other elements fall in a range of altered opacity to help the background create a theme foundation without overusing textile images or patterns for themed textures.

- Logo:
    - The brand's original logo was used as a starting point to develop the currently displayed logo. 
        
    - The original logo was AI created by the business owner and featured gibberish text that the owner disliked - this was removed.
        
    - The original logo used a colour palette that leaned towards a more feminine image and therefore would primarily appeal to a feminine market. This was altered to prevent turning away other potential customers. (I.e. to encourage non-feminine customers that they could find something for them as well.)
